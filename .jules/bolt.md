## 2024-05-24 - [Optimization Pattern for Results Counting]
**Learning:** Replaced multiple sequential chained array iterations (like `filter().length` and `reduce()`) with single-pass `for...of` loops. This prevents redundant object allocations and saves O(4N) traversals on large lists of result objects. While typical JavaScript engines try to optimize chained array methods, we empirically measured the single-pass loop to be substantially faster for these metrics in Node.js, fulfilling Bolt's performance ethos. This reinforces a broader codebase performance pattern where avoiding redundant arrays traversing on hot paths like metric counting is crucial.
**Action:** When performing aggregate counting across the same large arrays, default to single-pass standard `for` loops rather than combining `.filter()` and `.length`.
